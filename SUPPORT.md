# Support

Use the [GitHub issue tracker](https://github.com/alpinnz/valfuse-node/issues)
for questions about using valfuse-node, bug reports, and feature requests.

When reporting a bug, include the package and version, relevant runtime and
framework versions, steps to reproduce, and a minimal example. Remove secrets
and private user data before posting.

For security vulnerabilities, follow the [security policy](./SECURITY.md). Do
not report vulnerabilities in public issues.

For contribution guidance, see [CONTRIBUTING.md](./CONTRIBUTING.md) and the
[Code of Conduct](./CODE_OF_CONDUCT.md).
