## 3. Refactor / Architecture

### TASK-001
**Title:** Remove form re-export from core package
**Role:** Refactor
**Layer:** Domain / Infrastructure boundary
**Module:** packages/core
**Description:** Remove `export * from "@valfuse-node/form"` from `packages/core/src/public-api.ts`. Core should NOT re-export form domain logic — this creates wrong dependency direction. Core is orchestration only.
**Dependency:** None (first task)
**Acceptance Criteria:**
- [ ] `packages/core/src/public-api.ts` no longer contains `export * from "@valfuse-node/form"`
- [ ] Core package has no direct dependency on form domain types/functions
- [ ] Any remaining exports in core are orchestration-only or shared utilities
**Testing Requirement:** Verify build still passes, existing tests still pass
**Documentation Requirement:** Update core/README.md to reflect new role
**Risk Level:** High
**Priority:** Critical
**Estimated Complexity:** Low

---

### TASK-002
**Title:** Define and implement shared utilities in core
**Role:** Refactor
**Layer:** Domain (shared)
**Module:** packages/core
**Description:** Audit form and localization packages for common patterns/utilities that should be shared. Current candidate: `t` transformer from `packages/form/src/shared/transformers.ts` may be usable by localization. Implement shared utilities in `packages/core/src/shared/`.
**Dependency:** TASK-001 (core must be cleaned before adding shared)
**Acceptance Criteria:**
- [ ] Audit completed showing which utilities are shared
- [ ] Shared utilities implemented in `packages/core/src/shared/`
- [ ] Shared utilities have TypeScript types
- [ ] If transformers is shared, it compiles correctly in isolation
**Testing Requirement:** Unit tests for shared utilities
**Documentation Requirement:** Document what shared utilities exist and their purpose
**Risk Level:** Medium
**Priority:** Critical
**Estimated Complexity:** Medium

---

### TASK-003
**Title:** Add core dependency to localization package
**Role:** Refactor
**Layer:** Application / Infrastructure
**Module:** packages/localization
**Description:** Add `@valfuse-node/core` as a dependency in `packages/localization/package.json`. Localization should depend on core for shared utilities per user requirements.
**Dependency:** TASK-002 (shared utilities must exist first)
**Acceptance Criteria:**
- [ ] `packages/localization/package.json` has `@valfuse-node/core` in dependencies
- [ ] Localization uses shared utilities from core (if any exist)
- [ ] Build passes with new dependency
**Testing Requirement:** Verify localization build and tests still pass
**Documentation Requirement:** Update localization/README.md if behavior changed
**Risk Level:** Low
**Priority:** High
**Estimated Complexity:** Low
