# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `valfuse-node`, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Please email the maintainers directly or use the repository's private vulnerability reporting feature.

Include the following in your report:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 72 hours and work to address the issue promptly.
